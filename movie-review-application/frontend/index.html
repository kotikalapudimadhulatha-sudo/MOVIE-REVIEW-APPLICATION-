A full-stack movie review web application built with HTML5, CSS3, Vanilla JavaScript, Express.js, and Supabase PostgreSQL. Designed for cinema lovers and academic demonstration.

Tech Stack

  • ⚡ Frontend: HTML5, CSS3, Vanilla JS
  • 🚀 Backend: Node.js & Express.js
  • 🗄️ Database: Supabase PostgreSQL
  • 🔒 Security: XSS Sanitization & Input Validation
